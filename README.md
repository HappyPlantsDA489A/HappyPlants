# HappyPlants

## Scripts

### Delete All GitHub Issues

Need to clean up all issues in the repository? See the [scripts/README.md](scripts/README.md) for instructions on how to use the issue deletion script.

**Quick Start:**
```bash
cd scripts
chmod +x delete_all_issues.sh
./delete_all_issues.sh
```

⚠️ **Warning:** This permanently deletes all issues and cannot be undone!
